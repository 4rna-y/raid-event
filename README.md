# RaidEvent

プレイヤーの周辺 (200〜600m) にウェーブ制のレイドイベントを発生させる Paper プラグイン。
エンドラ討伐を目標にした wiah (誰か1人死んだらワールド全削除) サーバー向けに調整してある。

## 遊びの流れ

1. マインクラフト時間の1日ごとに 50% の確率でレイドが抽選され、その日のランダムな時刻に発生する
2. 発生すると、対象プレイヤー全員に地点 p を記した地図が配られる (名前にクレート種とレベル、説明に座標・昼夜・期限が書いてある)
3. 半日 (12000 tick) 以内に誰かが p の 16m 以内へ入るとウェーブ開始。村襲撃と同じ要領で全ウェーブを退けると、p に報酬チェストが設置される
4. 逃げてモンスターがデスポーンしたらレイドはキャンセル。誰も近づかず半日過ぎたら失効
5. 発動・失効・キャンセルのいずれでも、配った地図は全員の手元から回収される (死んだ地点を指す地図を残さない)

## レベルと進行度

オンラインのサバイバルプレイヤー (オーバーワールド在圏) の平均進行度スコアで基礎レベルが決まる。

| 要素 | スコア |
|---|---|
| 装着防具 (部位ごと) | 革・金 1 / チェーン 2 / 鉄 3 / ダイヤ 4 / ネザライト 5 |
| 最良武器 (剣・斧) | 素材で 0〜5 |
| エンチャント | 装備のレベル合計 ×0.5 (最大5) |
| 実績 | ネザー到達 +4 / ブレイズロッド +4 / 要塞発見 +3 / アイ or パール12個 +4 |
| ワールド経過日数 | 5日ごとに +1 (最大6) |

基礎レベル: 〜9 → L1 / 10〜 → L2 / 19〜 → L3 / 28〜 → L4 / 36〜 → L5 / 42〜 → L6 / 50〜 → L7 (昼の上限)。
**夜のレイドは +1 され、Level 8 は夜にしか出ない。**

### エンド後の節目 (L6〜L8)

目標は「エンドラ → ウィザー & ウォーデン」。エンド突入後は**ワールド単位の節目**が加点とレベルの上限になる
(`Milestones`)。討伐の実績はとどめを刺した 1 人にしか付かないので、節目はワールドで持つ:
エンドラはエンドのワールドが覚えている (`DragonBattle#hasBeenPreviouslyKilled`)、ウィザーとウォーデンは死亡イベントを見て
主ワールドの PDC に印を付ける (wiah でワールドが消えれば印も消える)。

| 要素 | スコア | 上限 |
|---|---|---|
| エンドラ討伐 | +6 | これが無いと L5 まで。あれば L6 |
| ウィザー討伐 / ウォーデン討伐 | 各 +6 | どちらかで L7、両方で L8 |
| エリトラ所持 | +3 | |
| ビーコン作成の実績かネザースター所持 | +3 | |

満点は 51 → 75。全員がネザー・エンドに居る間は抽選しない (変わらず)。

## モンスター

数は参加者2人基準。ウェーブ開始時に 48m 内の人数 n で ×(1 + 0.4×(n−2)) にスケール (1人なら ×0.6)。

| レベル | ウェーブ | 総数 | 強化 (HP/攻撃/速度) | 特徴 |
|---|---|---|---|---|
| L1 | 2 | 8 | 等倍 | ゾンビ・スケルトンのみ |
| L2 | 3 | 14 | 等倍 | クモ、金装備ゾンビ |
| L3 | 3 | 18 | ×1.2 / − / − | ピリジャー初登場、ヴィンディケーター1体 |
| L4 | 4 | 25 | ×1.5 / − / +10% | パワーI弓スケルトン、子ゾンビ |
| L5 | 5 | 32 | ×1.75 / +25% / +20% | 最終ウェーブに**エヴォーカー** (討伐でトーテム確定) |
| L6 | 5 | 38 | ×2.0 / +30% / +25% | ウィザースケルトン・ブレイズ・エンダーマン・ボグド。エンドラ討伐後 |
| L7 | 6 | 46 | ×2.25 / +40% / +30% | ピグリンブルート・イリュージョナー・ストレイ。最終ウェーブにエヴォーカー ×2 |
| L8 | 6 | 54 | ×2.5 / +40% / +30% | ダイヤの斧のヴィンディケーター。夜だけ |

攻撃は +40% で止める (ネザライト + 防護 IV で 3 ハート弱)。ピグリンはオーバーワールドでゾンビ化しないようにしてある。

死=ワールド消滅のサーバーなので、一撃事故を作らないことを最優先にしている:

- クリーパー (爆発+地形破壊) とラヴェジャー (ノックバック事故) は**パース時に拒否**。エンド後に足したガスト・ホグリン・
  ゾグリン・ブリーズ (吹き飛ばし)、シュルカー (浮遊 → 落下)、ウィザー・ウォーデン・エンドラ (目標そのもの) も同じ
- 遠距離 (弓・クロスボウ・ブレイズ・ボグド・ストレイ・イリュージョナー) は各ウェーブ4体まで (集中砲火の即死防止、これもパース時に検査)
- モブの装備ドロップ率は全部位 0 (レイドを装備の無料配布にしない)
- レイドモブは日光で燃えない (昼レイドの自壊防止)。型ごとの `setShouldBurnInDay(false)` に加え、
  日光由来の `EntityCombustEvent` をタグで一律キャンセルする (溶岩・火属性の攻撃は通す)

## 報酬クレート

3種 × 8レベル。チェスト27スロットのうち L1: 5〜8 / L5: 14〜19 / L8: 20〜25 スロットを重み付きで抽選。
L4 以上には「目玉確定枠」が1つある。中身の全表は `plugin/src/main/resources/config.yml`。

L6〜L8 はネザライトと最大エンチャントの領域。L6 以上の目玉枠には**特別なアイテム** (`custom:`) が混ざる:
異次元チェスト・スナイパーライフル・爆裂弓 (振る舞いは relics プラグイン)、モディファイア復活剤 (Modifier)。
`CustomItems` が土台 + PDC の印 + 名前で作り、持ち主のプラグインが居なければ名前の付いた飾りになる。
エリトラ (エンドシティ)・ネザースター (ウィザー)・メイスは出さない。

- **マイナー**: 鉱石+ツール。L5 はダイヤ8〜16、エメラルド、エンチャ付きダイヤピッケル (幸運III/シルク)
- **マジカル**: エンチャント本+ポーション。L5 は最大本 (修繕・鋭さV・幸運III・無限…) と最大ポーション (スプラッシュ・残留込み、落下速度低下あり)
- **ソルジャー**: 物資+武器+防具。L5 はエンチャダイヤ剣・防具、パワーV弓、金リンゴ

エンダーパールとブレイズロッドは**出さない** (エンダーマン狩りとネザー攻略という
ストーリーの背骨はスキップさせない)。トーテムの入手経路は L5 エヴォーカーの討伐ドロップのみ。

## 追加報酬 (クレートに依らない枠)

クレートの抽選は「スロットを N 個、`weight` の比で埋める」相対抽選なので、「クレートが何であれ
一定の確率で出す」ができない。そのための別枠が `extra-drops` (`ExtraDrops`)。
レイド成功のたびにエントリごとの独立したベルヌーイ試行を振り、当たったものを報酬チェストに入れる。

| アイテム | 排出率 | 下限レベル | 持ち主 |
|---|---|---|---|
| モディファイアリセットチケット | 8% | — | Modifier |
| リコールスクロール (1〜2枚) | 30% | L3 | manchor |
| 空間リコールスクロール | 15% | L4 | manchor |
| 緊急リコールスクロール | 10% | L5 | manchor |

スクロールに下限レベルがあるのは、アンカーを建てていないと使えないから。
以前は Mamble の交換機で買えたが、入手経路をレイドに一本化した。

追加報酬はクレートの中身より**先に**スロットを取る。L8 (最大 25 スロット) に 4 つ当たると 27 枠を
超えるので、削られるのはクレートの側。

## コマンド

- `/raidevent` (`/re`) — 進行中のレイドの確認 (誰でも)
- `/re status|spawn <level> <crate> [player]|cancel|reload` — 管理 (`raidevent.admin`)

## 開発

```
nix develop
gradle :plugin:test      # ユニットテスト
gradle :e2e:e2eTest      # 実サーバー+ヘッドレスクライアントでの通し検証 (数分)
raidevent-dev            # ビルド → 配置 → ./run で起動
```

E2E は 26.1.2 のサーバーを立てる (mineflayer が 26.2 のプロトコルに未対応のため)。
jar は本番と同じ 26.2 ビルドのものを載せる。

## 設計メモ

- レイドは同時に1つ。再起動で消える (wiah 前提のサーバーで永続化しても整合しない)
- デスポーン検出は `EntityRemoveEvent` (DESPAWN / UNLOAD)。チャンクごとアンロードされて
  観測できないケースの保険に、参加者不在 (96m / 2分) の放棄キャンセルもある
- 数値は全部 config.yml にある。難易度調整はコードを触らずにできる
- 地図にはレイドの id を PDC (`raidevent:raid-id`) で焼き込んである。回収はこの id で
  持ち物・エンダーチェスト・落ちているアイテムを走査する (オフラインの分は残る)
- `Bukkit.createMap()` の地図は位置追跡が切れているので、`setTrackingPosition(true)` と
  `setUnlimitedTracking(true)` を明示的に入れている。後者が無いと地点から 320m 超で
  自分のインジケータが消える (配布時点の距離は 200〜600m)
